# Palworld TCG Collection Manager

A Python and Microsoft SQL Server application for managing a personal Palworld Trading Card Game collection.

## Current features

- Connects Python to SQL Server
- Stores card sets, cards and collection entries
- Uses primary keys, foreign keys and data validation constraints
- Reads card set information from the database

## Technologies

- Python
- Microsoft SQL Server Express
- T-SQL
- pyodbc
- Git and GitHub

## Status

This project is currently in development.
